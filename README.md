# English Fluency AI — Android Conversational Tutor (BBC Learning English + Gemini Multimodal)

Нативное Android-приложение (**Kotlin + Jetpack Compose**) для тренировки разговорного английского языка на основе выпусков **BBC Learning English (6 Minute English)** и мультимодальной модели **Google Gemini 2.5 Flash**.

---

## ✨ Возможности (MVP v1.0)

### 1. Парсинг уроков BBC Learning English (`LessonsHubTab`)
* **Импорт по URL:** вставьте ссылку на выпуск *BBC 6 Minute English* (например, `ep-261029`), и приложение автоматически скачает страницу (`Jsoup`), извлечет транскрипт, целевые идиомы, их определения, переводы на русский, синонимы и вопросы для дискуссии.
* **Предзагруженные уроки:** сразу доступны уроки по темам цифровых привычек (`ep-261029`) и бизнес-идиом для рабочего общения.

### 2. Голосовой ИИ-тьютор в режиме Push-to-Talk (`PushToTalkCoachTab`)
* **Двойной захват речи:**
  * Запись аудиофайла `.m4a` (`MediaRecorder` AAC) для отправки сырого звука напрямую в мультимодальный **Gemini 2.5 Flash**.
  * Живая расшифровка речи (`SpeechRecognizer`) на экране во время говорения.
* **Комплексный разбор каждой реплики (`SpeechAnalysis`):**
  * **Target Vocabulary:** проверка использования целевых слов и идиом из урока + подсказка, какую фразу уместно ввернуть дальше.
  * **Native Phrasing:** как эту же мысль естественно выразит носитель языка (с озвучкой по клику).
  * **Grammar & Accuracy:** разбор грамматики на русском языке + исправленное предложение.
  * **Pronunciation & Intonation:** оценка произношения (%), ударений, связок слов (*linking*) и интонации по аудиозаписи.
  * **Repeat Prompt:** кнопка быстрого повторения эталонной фразы вслух.

### 3. Активный SRS-тренажер интервального повторения (`SrsActiveTrainerTab`)
* Сохранение прогресса освоения каждого выражения (`0..5`) и расчет интервалов повторения (`1, 3, 7, 14, 30 дней`).
* **3 разговорных режима проверки (голосом через Push-to-Talk или текстом):**
  1. **RU → EN:** перевод русской фразы вслух с обязательным использованием изучаемой идиомы.
  2. **EN → EN (Paraphrasing / Синонимы):** перефразирование простого английского предложения через целевое выражение из урока.
  3. **Контекстный ответ (Situational Q&A):** устный ответ на вопрос тьютора с применением выражения.
