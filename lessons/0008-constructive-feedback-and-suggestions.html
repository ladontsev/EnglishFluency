Lesson 08 • Constructive Influence

Suggesting Alternatives: Influence Without Bossiness

⏱ Estimated time: 12 mins 🎯 Level: Pre-Intermediate → Intermediate ⚡ Goal: Propose ideas & critique code/plans without sounding bossy

1. The "You Should" Trap in Code Reviews & Planning

Using imperative commands like "You should change this" or "Do not use this approach" triggers defensiveness. Tech leads and senior engineers pitch ideas collaboratively using suggestion stems:

❌ Sounds Bossy / Dictatorial:
"You must use Redis here. Your solution is slow."
✅ Collaborative & Senior:
"Have you considered using Redis here? It might help with latency under heavy load."

2. 4 High-Impact Suggestion Stems

Use these stems to present suggestions with authority and tact:

"Have you considered...?"
«А ты не думал о том, чтобы...?» (+ V-ing)
"Have you considered splitting this into two microservices?"
"What if we were to...?"
«Что, если нам поступить так: ...?» (Мягкое предложение)
"What if we were to test it with 5% of users first?"
"It might be worth looking into..."
«Возможно, имеет смысл изучить / присмотреться к...»
"It might be worth looking into indexed queries."
"One potential drawback might be..."
«Одним из возможных минусов может быть...»
"One potential drawback might be the maintenance cost."

4. Architectural Review Simulator

Choose the most collaborative and influential response:

"A junior developer submitted a PR containing a 500-line monolithic function."
"The team wants to release a big refactoring on Friday evening at 6 PM."

🎧 Pro-Pitch: Suggesting an Architecture Alternative

Listen to how senior engineers suggest a change:

"I see the logic behind this plan. One potential drawback might be scaling issues later on. What if we were to look into a queue-based solution instead?"
