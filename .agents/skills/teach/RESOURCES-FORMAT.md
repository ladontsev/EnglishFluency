# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Knowledge for explainers should be drawn from here, not from parametric guesses. Wisdom comes from the communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _Title_ — Author](https://example.com)
  Foundational text or reference. Use for: specific concepts, syntax, deep dives.
- [Article: "Title" — Author](https://example.com)
  Evidence-based guide. Use for: practical recipes, benchmarks.

## Wisdom (Communities)

- [Community / Forum](https://example.com)
  High-signal community. Use for: real-world nuances, troubleshooting.
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work, and official specs.
- **Keep it curated.** Not a link dump — each resource must have a clear "Use for" purpose.
